# Money Tracker

A React app to track income and expenses with a bar chart visualization.

## Features
- Add income/expense transactions
- Edit and delete transactions
- View balance, total income, expenses
- Bar chart comparing income vs expenses

## Technologies
- React
- Recharts
- CSS

## How to run
1. Clone the repo
2. `npm install`
3. `npm run dev`
